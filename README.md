# AI-Powered-Emotion-Detection-Web-Application
A Flask-based backend API integrated with IBM Watson NLP service for real-time text emotion detection and vector analysis.

A production-ready Python web application that leverages IBM Watson's NLP runtime libraries to perform fine-grained emotion detection on text inputs. Built with Flask, this application analyzes text to extract scores for multiple emotional vectors and identifies the dominant emotion.

## 🚀 Features
- **Deep Text Analytics:** Integrates with Watson NLP Service to evaluate text for 5 core emotions: anger, disgust, fear, joy, and sadness.
- **Robust REST API:** Lightweight Flask backend handles asynchronous analysis requests via clean GET/POST processing.
- **Dynamic Frontend Interface:** Responsive UI utilising Vanilla JavaScript AJAX calls for seamless user experience without page reloads.
- **Enterprise Standards:** Fully covered by automated unit tests and strictly compliant with PEP8 styling guidelines.

## 🛠 Tech Stack
- **Backend:** Python 3, Flask, Requests
- **AI/NLP:** IBM Watson NLP Runtime API
- **Testing:** Unittest
- **Frontend:** HTML5, Bootstrap 4, JavaScript (ES6)
